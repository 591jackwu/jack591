# 奶娃大笑遊戲 (Naiva Laughing Game) 🤣

專為魔性大笑奶娃量身打造的高手速點擊反應遊戲！
本專案已將原本單一的 HTML 程式碼完整重構分離為標準的前端三層架構（**HTML**、**CSS**、**JS**），並進行多項視覺特效與玩法系統優化。

---

## 📁 檔案架構

請確保以下檔案位於同一資料夾內：

```text
naiva-game/
├── index.html       # 遊戲主要結構與視窗佈局
├── style.css        # 視覺設計、玻璃擬態 UI、星空粒子與動態特效
├── game.js          # 遊戲邏輯、連擊系統、雙軌音效與資料持久化
├── naiva.png        # 奶娃角色圖檔 (透明背景 PNG)
└── README.md        # 專案說明與客製化教學
```

---

## 🚀 如何啟動遊戲

1. **直接雙擊開啟**：
   在電腦檔案總管中，直接雙擊點擊 `index.html` 即可在任一現代瀏覽器（Google Chrome, Edge, Safari, Firefox）中暢玩。
2. **透過本機伺服器（推薦）**：
   如需獲得最流暢的 YouTube 音訊自動載入體驗，可使用 VS Code 的 `Live Server` 延伸模組，或在終端機執行：
   ```bash
   npx serve .
   # 或
   python -m http.server 8000
   ```
   瀏覽網址：`http://localhost:8000`

## ✨ 優化亮點與全新特色

1. **完整檔案模組化拆分**：
   - 告別所有代碼擠在單一 HTML 的混亂，HTML 專注 DOM 結構，CSS 專注動畫美學，JS 專注遊戲邏輯。
2. **雙引擎音效系統**：
   - **YouTube 官方音樂串流**：內嵌播放您指定的官方背景音樂。
   - **Web Audio API 擬真合成音效**：即便無網路或 YouTube 阻擋自動播放，也能即時合成逼真魔性笑聲、連擊和弦音與歡樂旋律。
   - 支援隨時點擊右上角 `🔊 / 🔇` 切換靜音。
3. **連擊系統 (Combo) & 狂熱模式 (Fever Mode)**：
   - 連續命中不失手即可堆疊 Combo：
     - 1~2 擊：基礎得分（+10 分）
     - 3~4 擊：連擊加乘（+20 分）
     - 5 擊以上：進入 **🔥 FEVER 狂暴大笑模式**，全螢幕泛金光特效，得分狂飆（+30 ~ 40 分）！
   - 點擊到空白背景或漏掉奶娃會重置連擊數。
4. **隨機稀有「黃金金奶娃」登場**：
   - 約 18% 機率現身散發耀眼光芒的黃金奶娃，點擊獲得 **3 倍暴擊分數** 與專屬和弦爆破粒子！
5. **動態節奏加速機制**：
   - 隨著倒數計時進入尾聲，奶娃冒出頻率從 900ms 逐步縮短至 500ms，挑戰極限手速！
6. **三種遊戲時長選擇**：
   - ⚡ 15 秒（極速練手）
   - ⏱ 30 秒（標準經典）
   - 🔥 60 秒（極限狂歡）
7. **歷史最高分持久化儲存 (LocalStorage)**：
   - 自動將玩家的最高紀錄保存在瀏覽器，挑戰打破自己的紀錄！
8. **結算評等與命中率統計**：
   - 統計命中率 (%) 與最高連擊數，並授予對應稱號（至尊神手、大笑大師、手速高手等）。
9. **暫停與全平台適配**：
   - 隨時可點擊 `⏸` 暫停遊戲。
   - 支援行動裝置觸控防誤觸及多點觸控。

## 🛠️ 自訂與修改設定指南

在 `game.js` 最上方的 `CONFIG` 物件中，可輕鬆自訂遊戲參數：

```javascript
const CONFIG = {
  imgSrc: 'naiva.png',        // 角色圖片路徑
  defaultTime: 30,            // 預設遊戲秒數 (秒)
  maxOnScreen: 6,             // 畫面上同時存在的最大奶娃數量
  goldenChance: 0.18,         // 黃金奶娃出現機率 (0.18 = 18%)
  ytVideoId: 'Y2Xn97vhgsQ',    // YouTube 影片 ID (可換成其他音樂)
  localStorageKey: 'naiva_high_score_v1'
};
```

- **更換 YouTube 音樂**：
  若想換成其他 YouTube 歌曲，只需複製網址中 `v=` 後面的 11 碼英數（例如 `https://www.youtube.com/watch?v=XXXXXXXXXXX`），把 `CONFIG.ytVideoId` 改為 `'XXXXXXXXXXX'` 即可。
- **更換角色圖片**：
  將您喜愛的任何透明背景圖片命名為 `naiva.png` 置於同目錄下，即完成替換。
